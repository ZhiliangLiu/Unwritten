# Unwritten 第四个里程碑：插图与出图服务

**目标：** 沿着[第三个里程碑](./milestone-3.md)的路径，让故事在关键时刻有画面，并且同一个人物前后长得一样。

- **出图是基础能力。** core 通过协议接入出图服务，只看服务报告的能力，不认具体的服务。支持两种协议：自家的 Unwritten 图像协议，以及 OpenAI 图像接口（[插图与出图服务](./image.md)）。
- **插图在关键时刻出现。** 开场画一张；之后由 narrator 判断高潮，是高潮就画。插图在回合提交之后生成，从不挡住正文。
- **人物前后一致。** 每个人物都有一段看得见的形象和一张参考立绘：作者在方案里定主要人物的形象，玩家开局时定主角的形象，其余由 AI 写。画风由作者给默认值，玩家开局时可以改，开局后锁定。
- **插件机制与 ComfyUI 插件。** 插件是实现 Unwritten 协议的独立服务，不载入 core（[插件](./plugins.md)）。`plugins/comfyui/` 用 Qwen-Image-2.1 实现 Unwritten 图像协议，可以部署在 Google Colab 上，经 Tailscale 只让你自己的 Mac 访问（[ComfyUI 插件与 Colab 部署](./comfyui-plugin.md)）。

交付方式：维护者在本机运行 desktop 的开发模式或打出的包，出图服务用 Colab 上的 ComfyUI 插件，或者一个 OpenAI 兼容的图像接口。没有配置出图服务时，应用的行为和第三个里程碑完全一致。

## 作者和玩家能做什么

| 环节 | 可交付的体验 |
| --- | --- |
| 配置出图服务 | 设置页的「出图服务」一节：添加 Unwritten 图像协议或 OpenAI 兼容的服务，生成令牌，测试连接，看到实现名、模型、是否就绪和能力；切换「游玩时生成插图」；看到出图用量和插图占用的空间。没配服务时，别处不出现任何和插图有关的入口 |
| 作者定形象与画风 | 补充设定里有一节收起的「插图」，可以选默认画风并预览。故事方案里每个人物都有形象文字，标出来自作者还是 AI；可以为人物生成立绘、重画。不画立绘也能确认方案 |
| 开局 | 开局页有一块收起的「插图」：画风（默认是作者的，可以改）、主角形象（可以让 AI 按设定写一个）、主角是否入画，预填上次的选择。可以预览画风；离线时预览不可用，但不影响开局。注明开局后不能再改画风 |
| 读到插图 | 开场第一段之前、被标为高潮的段落之后各有一张插图。回合一出现，占位就按最终的宽高比占好，图到达时只填进去，阅读位置不动。占位依次显示「排队中」「正在画这一幕」；失败时收成一行，写明原因并提供「重试」「不要这张图」 |
| 看大图 | 点插图打开大图，下方是画面说明，可以「重画」「保存图片」 |
| 手记里的立绘 | 手记的人物条目显示立绘缩略图，只对主角见过的人物显示 |
| 关掉插图 | 关闭「游玩时生成插图」后不再生成新图，已画好的照常显示 |

## 实现顺序与检查点

1. **外发请求的统一出口。** 把 `llm` 模块里不跟随重定向的 `fetch` 封装抽成 `net` 模块，`llm` 改为经过它。重定向的验收用例照常通过。[插图与出图服务 §5.2](./image.md#52-外发请求) · [LLM 端点 §3](./llm-endpoints.md#3-key-的来源与保护)
2. **出图服务的配置。** `providers.json` 升到版本 2，新增 `imageServices` 和 `image`；设置页的「出图服务」一节；令牌生成；`app_settings` 里的插图开关。[插图与出图服务 §2](./image.md#2-出图服务的配置)
3. **Unwritten 图像协议。** `image` 模块的协议客户端、伪服务和一致性测试；扫描源码、禁止出现插件专属名字的测试。[插件 §2–3](./plugins.md#2-边界) · [插图与出图服务 §3](./image.md#3-unwritten-图像协议)、[§5](./image.md#5-image-模块)
4. **OpenAI 图像接口。** 文生图与编辑两条路径、尺寸与能力预填、错误映射。[插图与出图服务 §4](./image.md#4-openai-图像接口)
5. **形象。** 实体档案的 `appearance`、方案里人物的形象、`propose_cast` 与 `new_entity` 的必填形象、`appearance` 特征、开局行的插图设置。[插图与出图服务 §6.1](./image.md#61-形象) · [数据模型 §2–4](./data-model.md#2-作品与版本) · [回合循环 §5](./turn-loop.md#5-提交一回合propose_turn-与-ask_clarification)
6. **插图的流程。** `propose_turn` 的 `illustrate`、`turns.illustrate_para`、提交与采用时插入插图记录、镜头描述（不带工具的固定格式输出）、立绘、场景图、重试与重画，以及[插图与出图服务 §10](./image.md#10-交给-client) 列出的插图和立绘过程。[插图与出图服务 §6.2–8](./image.md#62-立绘)
7. **存储与交付。** `images/` 目录、两张表、写入顺序、清理、`image.file`、blob URL 与内容安全策略、手记立绘的投影、事件、调用记录与诊断。[插图与出图服务 §9–11](./image.md#9-存储) · [架构总览 §2.1](./architecture.md#21-本机接口的安全)
8. **界面。** 设置页、补充设定的「插图」节、方案里的形象与立绘、开局页、游玩页的占位与大图、手记缩略图。[游玩流程 §2.1](./gameplay-flow.md#21-插图) · [设计准则 §9](./design-guidelines.md#9-部件) · [动效 §5](./motion.md#5-场景编排) · [a11y §8](./a11y.md#8-游玩页)
9. **ComfyUI 插件。** 包装服务、四份工作流模板、模型锁定、笔记本、README、伪 ComfyUI 与 pytest、CI 里的一致性测试，以及仓库里插件目录的工具链（uv、ruff、pytest、lefthook）。[插件 §6](./plugins.md#6-仓库里的插件) · [ComfyUI 插件与 Colab 部署](./comfyui-plugin.md)
10. **端到端与评测。** 浏览器模式用伪服务覆盖开局到插图的全程；在 `evals/` 加高潮标记和形象只写外观的评测用例；维护者在 Colab 上按插件文档的验收表走一遍。

1–4 在 core 和 contracts 的 `image` 一侧，9 只在 `plugins/` 里，两条线只在协议规范上相交，可以并行。5–8 依赖 1–4。

## 留给后续的能力

| 能力 | 推迟的理由 |
| --- | --- |
| Gemini、A1111、阿里云百炼等其他协议 | 可以在服务前面加一层实现 Unwritten 图像协议的代理来接入，core 不用改 |
| 服务端原生画风（例如画风对应到服务器上的 LoRA） | 画风预设要和服务器上装的模型一一对应，复杂度明显上升 |
| 手动「画这一幕」、插图的图集与导出 | 自动插图先跑一段时间，看缺不缺这些 |
| 生成进度的百分比 | OpenAI 图像接口不报告进度，占位保持安静 |
| 游玩中途改画风 | 一局之内画风不变，一个形象在一局里只需要一张立绘 |
| 单独删除一局及其图片 | 目录已经按开局分开，删除流程和确认另做 |

## 验收

| 从什么情况开始 | 操作 | 应当看到的结果 |
| --- | --- | --- |
| 没有配置出图服务 | 走一遍第三个里程碑的验收 | 结果完全相同，界面上没有插图相关的入口 |
| 设置页 | 添加一个 Unwritten 图像协议的服务并生成令牌，离开页面再回来 | 令牌只在生成时显示过一次；之后只显示「已配置」和来源 |
| `providers.json` 是版本 1 | 启动应用，添加一个出图服务 | 原有的模型配置都在；文件变为版本 2，旧文件存为 `providers.json.bak` |
| Colab 上的 ComfyUI 插件已就绪 | 测试连接 | 显示 ComfyUI、Qwen-Image-2.1、就绪，以及最多 10 张参考图、负面提示词不生效 |
| 作者设定了两位固定人物 | 生成方案，为他们生成立绘，开局并玩到两人同框的高潮 | 插图里两人的长相和立绘一致；画面说明只用主角知道的称呼 |
| 玩家开局时改了画风，主角形象留空并选了入画 | 开局 | 开场插图用玩家选的画风，主角入画；开局之后，画风无法再改 |
| 服务离线 | 玩到一个高潮 | 占位很快显示失败和「重试」；服务上线后点「重试」画成 |
| 玩家正在往上读前文 | 一张插图到达 | 阅读位置不动 |
| 手记里有一位只听说过的人物 | 打开手记 | 他的条目没有立绘 |
| 使用 OpenAI 兼容的服务 | 玩到一个带参考人物的高潮 | 走编辑接口，结果按实际宽高显示；被服务拒绝时显示「出图服务拒绝了这张图」 |
| 删除一部有插图的作品 | 重启应用 | 这部作品的图片目录都被删除 |
| 系统开启减少动态效果 | 等一张插图生成并到达 | 占位不呼吸，图片直接淡入，没有位移 |
