# Unwritten · 游玩流程

**产品体验设计 · 玩家视角**

玩家从本机作品库走进一部文字冒险，阅读一段完整剧情，选择或输入自己想做的事。AI 根据作品设定、此时在场的人物和这条路线的经历作出回应。此前认识的人、透露的秘密、履行或错过的约定，可以在很多回合后重新影响剧情。所有作品共用「阅读 → 行动 → 回应 → 更新进度」这条路径。追踪哪些状态、有哪些人物以及是否有明确结局，取决于作品设定与本路线的经历。作品的起点由[创作流程](./authoring-flow.md)决定。

**一次连续发展的经历称为「路线」。** 自动续玩带玩家回到路线的最新进度。手动存档留下一个具体决定点。故事手记则帮助玩家从已经发现的事情找回原文。

## 1. 进入作品，找到正确的起点

| 作品当前状态 | 主要入口 | 进入后 |
| --- | --- | --- |
| 尚在创作 | 继续创作 | 返回作者草稿。作品保存为可玩后才提供正式开局。 |
| 已可玩，第一次进入 | 开始故事 | 如果作者给主角留了填写项，只问这些内容；随后读到作者采用的开场。配了出图服务时，另有一块收起的「插图」，可以选画风、写主角形象、决定主角是否入画（§2.1）。 |
| 有进度 | 继续游玩 | 卡片用路线名、时间地点或最近事件提示将从哪里接上。进入后读到最近一段完整剧情和当时的行动。 |
| 有多个进度 | 所有路线 | 选择要继续的一条。作品卡默认指向最近游玩的路线，作者试玩有独立入口。 |
| 最近路线已结束 | 回看结局 / 所有路线 / 重新开局 | 重读已经走完的故事，找之前的决定点，或从当前作品开场重新开始。 |

每部作品有一个开场。主要角色是否每局相同由作者决定。即使每次新开局遇见不同的人，作者确定的时间、地点和处境仍然成立。开场完整呈现后，当前开局成为可续玩的进度，即使还没做第一次选择也可退出。主角的开局填写结果、已生成的人物及其经历随路线保留。

## 2. 读一段，决定一步

用文字呈现场景、旁白和人物对白。启用本局插图时，开场和适合入画的关键场面配图（§2.1）。每次读到的都是一段完整剧情，玩家可以按自己的速度向下读。最新段落之后是当前状态，再往下是可选行动和自由输入。状态可以展开查看。上下滑动只移动阅读位置。

| 时刻 | 玩家可以做什么 | 玩家会看到什么 |
| --- | --- | --- |
| 抵达决定点 | 读正文、查看状态、打开手记，或先手动存档 | 可以分清此刻在哪里、发生了什么、有哪些行动方向。 |
| 选择推荐行动 | 点击一句符合自己意图的行动 | 原句出现在叙事中，其余推荐行动不会成为已经发生的事。按作者选择，可只显示行动，或在选择前提醒玩家已知的利害。 |
| 自由输入 | 写一句对白，一个动作，或两者兼有，主动发送 | 输入的原话保留。空白时留在输入位置；已有文字又点推荐项时，让玩家选择采用选项或继续编辑。 |
| 等待续写 | 留在最新位置、向上读前文，或返回作品库 | 已提交的行动清楚可见，只发出一次。若玩家正在翻阅，完成后保留阅读位置，提供「回到最新」。 |
| 读到回应 | 整段读完，再看当前状态、新选项和自由输入入口 | 新段落紧接刚才的行动，先回应玩家实际做的事，再推进局势。明确哪些变化已保存。 |

持续游玩时，页面依次保留「剧情、实际行动、下一段剧情」。只有最新决定点展示可操作的选项和当前状态栏。过往行动和原文可以随时重读。

### 谁决定行动的结果

玩家决定主角的行动和重要表态。AI 可以补充符合原意的日常对白或动作细节。凡是会替玩家作出承诺、表明立场或披露信息的决定，都把选择交回玩家。行动的结果受当前处境、世界规则与其他人物意愿影响。

自由输入能够结合场景理解时，直接续写。若不同理解会产生不同后果，先保留原话，请玩家明确对象或意图。澄清期间停在原决定点。行动受阻时，写出主角能感知的结果，让玩家决定如何应对。

> **示例 · 日常对白与承诺。** 玩家选择递伞，AI 可以补一句「路上小心」。对方问「明天还会等我吗？」时，由玩家回答。

每次续写都应能接回这条路线中有关的设定、人物、地点及旧事。每个角色依据自己经历或听说过的事行动。玩家私下得知的消息，另一位角色要有机会听到或观察到，之后才能自然地提起。第一次见面、听说过对方和已经相熟也应有不同的表现。AI 根据作者写下的触发条件和本路线的实际经历判断何时安排关键场面；抵达场面后，主角怎样回应仍由玩家决定。

### 2.1 插图

没有出图服务、服务离线或画失败时，正文和行动照常可用。

**开局时选本局的样子。** 配了出图服务时，「插图」默认收起，摘要显示「本局插图 · 水彩 · 自动比例 · 1K」或「本局纯文字」。设置里主动开启「游玩时生成插图」后，新开局默认有插图，玩家可以改选「本局纯文字」。直接点「开始故事」就用摘要里的选择。纯文字开局始终以文字游玩。

| 项 | 玩家可以做什么 |
| --- | --- |
| 画风 | 从预设里选，或者写一句自己的画风。默认用作者的画风。同一作品再次开局时，沿用上次主动选的画风，也可以恢复作者默认 |
| 画面比例 | 默认「自动」，每张图按镜头内容决定。希望整局画框统一时，可以固定为服务支持的比例 |
| 分辨率 | 选择「高 · 720」「很高 · 1K」或「非常高 · 2K」，只显示当前服务能提供的档位。默认用设置页的选择。选项附上实际像素尺寸，自动比例下可展开查看各比例的尺寸。只提供默认尺寸的服务显示「服务默认」 |
| 主角形象 | 用一句话写主角看起来的样子，例如「短发，旧风衣，左手缠着绷带」；也可以点「按设定写一个」，让 AI 根据作者的主角设定起草 |
| 主角是否入画 | 「画进插图」，或者「用主角视角，不画主角」。选了入画却没写形象时，AI 按设定写一个 |
| 预览画风 | 用一张固定题材的示例图看画风效果 |
| 主角参考 | 选「画进插图」时，可导入一张正面图，也可按形象生成预览。看到满意的图后点「用作本局参考」。想补斜侧脸或全身时再展开对应位置 |

直接开始故事也可以。「用作本局参考」只选定当时已就绪的图。想加入后来画好的视角，可以在开局前再选一次。还没选定时，第一次需要画主角再按本局形象准备参考。画风开局后锁定。服务离线时，仍可选本机图片，预览生成显示离线原因，开局照常。

**读到插图。** 开场有可以提前公开的初始处境时，图放在第一段之前。之后，从本回合挑一个看得见、值得停留的瞬间，在对应段落之后配图。同一个人物用固定的外观参考，姿势、表情和衣服按当时发生的事来画。

| 适合配图的情况 | 可以画什么 |
| --- | --- |
| 人物的动作与反应 | 伸手接住被风吹走的车票。看完信后，把桌上的第二只杯子收进柜子 |
| 人与人的互动 | 把钥匙递给对方、伸手又缩回。重逢时两个人隔着门槛对望，或有一人先向前一步 |
| 多人协作或对峙 | 一个人托住歪斜的梯子，另一个探身够窗沿。两个人同时把手按在同一份地图上 |
| 玩家行动带来的可见后果 | 玩家扳下闸杆后，空荡的候船厅重新亮起来。可以从主角视角画这个变化 |
| 线索和物件 | 信封上被挑开的封蜡、从旧怀表里露出的一截陌生齿轮。用近景照顾主角真正看见的细节 |
| 地点和环境变化 | 第一次看见退潮后露出的栈道。起雾后，原来看得见的灯塔只剩一点灯光 |

安静的动作、短暂停顿也可以入画，只要它让关系、处境或线索更容易看清。例行走路、重复交谈等可以继续用文字带过。一段里有好几个动作时，插图定格最有叙事意义的一刻。同一回合最多一张，优先考虑玩家刚作出的决定所带来的可见变化。

| 时刻 | 玩家看到什么 |
| --- | --- |
| 回合刚出现 | 已知比例时立即留出画框。自动比例尚未确定时先显示一行「正在构思画面」，定好构图后展开为对应比例的画框。过高的竖图会等比缩小留在正文中，可以点开看大图。正文和行动立即可用 |
| 图到达 | 图在框里淡入，不播报、不滚动，不打断阅读。深色主题下图片略微调暗，免得一大块亮色突然出现 |
| 出图服务正在唤醒 | 出图服务配了按需启动、此刻关着时，占位写「正在唤醒出图服务」。冷启动可能要等好几分钟，正文和行动照常可用 |
| 需要授权 | 页面上出现一条不会自动消失的提示：「出图服务需要你在浏览器里完成授权」，带「打开授权页」和「继续」。在浏览器里允许后点「继续」，唤醒接着进行。占位写「等待你完成授权」 |
| 画失败 | 框收成一行，说明原因并提供「重试」和「不要这张图」。服务回来后，玩家只重试选中的图 |
| 点开插图 | 大图下有画面说明和实际分辨率。可以「重画」「保存图片」或「不要这张图」。重画沿用原比例和明确选定的尺寸。原图用的是服务默认尺寸时，按该服务默认重画，并显示实际像素。画成了才替换 |

- 画面和说明以图所在段落为准。后面才揭晓的脸、称呼或真相，要等玩家读到那里。行动还在等待玩家选择时，可以画眼前的局面，选择后的结果留到行动发生之后。
- 「换一种发展」时，在满足出图条件且候选标有插图的位置显示「采用后再画插图」。采用后才开始画。原版的图留在原版上。
- 出图服务配了按需启动时，进入开了插图的开局就开始唤醒，不等第一张图。服务连续空闲到设置页设的分钟数，会自己关闭；之后再有图要画，就再唤醒一次。
- 关闭「游玩时生成插图」会停止本机游玩出图，未完成的占位收起，已画成的图照常显示和保存。重新开启后，从接下来的回合继续。作品试玩也遵守这条规则。
- 画框展开，或插图收起、重试、移除时，正在读的正文留在原处。键盘焦点在被移除的插图操作上时，回到所属段落。开场图移除后，焦点到开场第一段。
- 手记只给主角见过、且有可用参考图的人物显示缩略图。缩略图按当前路线已看到的形象选取。

## 3. 保留刚才的行动，重写最新回应

当新一段已完整呈现、下一次行动还没提交，玩家可以点「换一种发展」。这适用于玩家认可自己刚做的决定，却想看另一种演出。候选从这次行动发生前的同一处境出发，保留玩家原话和此前的事实。上一版回应里才揭晓的秘密、人物反应和物品去向，不能预先带进候选。开场没有玩家行动，不提供「换一种发展」。每局生成人物的作品，重新开局会遇见新的人物和重写的开场；固定人物的作品，开场始终是作者采用的那一份。

1. **提出重写。** 可直接生成，也可以选填一句偏好，如「让这一幕更含蓄」。这句只影响叙述，不成为主角台词、世界事实或手记内容。
2. **比较结果。** 原回应仍可阅读。候选展示自己的正文、状态变化和下一步选择供比较。先点「采用这一版」或「沿用原版」结束比较，再从选定版本行动或手动存档。
3. **采用或返回。** 选定候选后，在原来位置替换本段，状态、人物记忆、选项和故事手记一同对应所选结果。仅在原版中发生的事件及其后果随版本切换一起移出这条路线。取消、失败或比较中离开时，原回应仍是续玩位置。
4. **继续。** 提交下一次行动后，上一段成为历史。想改变早先采取的行动，可以从当时留下的手动存档开启另一条路线。重写前已建立的手动存档保留当时的版本。

## 4. 看当前状态，查过去发生的事

| 想知道什么 | 去哪里 | 出现与更新的依据 |
| --- | --- | --- |
| 现在要留意什么 | 最新段落的状态栏 | 显示作者设置的当前进度、人际关系、约定等。数值或描述按作品定义的变化条件更新。故事时间指剧情里过了多久，目标进度指作者设定的目标完成到哪一步，回合数指玩家行动了几次，三者互不换算。状态栏只显示作者设定或 AI 新增的栏目。数字可以带进度条，阶段显示走到了第几步，清单逐项标明进行中、已完成或落空。本回合变了的栏目标出变化：数字的增减、文字原来的样子、清单里的新条目。点开任一栏目，能看到它的来历并跳回当时的原文。 |
| 有新的情况需要持续跟踪 | 状态栏里适合的现有栏目，或 AI 新增的栏目 | 在实际变化已发生、玩家已经知道且有助于之后决策时显示。事情结束后更新或收起栏目，收起的栏目留在状态栏末尾的「已了结」里，手记仍可保留来历。 |
| 我怎么认识这个人，线索从哪来 | 自动更新的故事手记 | 按已知人物、地点或事件找简短记录，点出处跳回本路线原文。听说过一个人时可记下是谁提起了他，实际相遇后才记「第一次见面」。见过的人物带参考图缩略图。 |
| 对方当时到底说了哪句话 | 连续剧情原文 | 可从手记跳转或直接向上滑。点「回到最新」回到当前决定点，阅读历史不会改写进度。 |

正文负责演出，状态栏只在变化对当前决定有用时提示，手记保存可追溯的已知经历。三者都遵循本路线的揭晓进度，别的路线发生的事和作者私下看过的设定均不会提前出现在玩家面前。采用重写后，失效的手记条目及出处同步更新。

## 5. 离开、存档和尝试另一条路

| 玩家意图 | 操作 | 回来后，哪一段经历属于这条路线 |
| --- | --- | --- |
| 下次接着玩 | 看到进度已保存后离开，再点「继续游玩」 | 回到最新完整段落，看到当时的状态和可用行动。 |
| 留下决定前的时刻 | 在决定点点「手动存档」，采用建议名称或改名 | 保存段落、当时的状态和待选行动。列表附所属路线、时间地点或最近事件。存好后仍可沿原路线继续。 |
| 从过去做不同的事 | 在存档列表预览一个节点，点「从这里另开路线」 | 从存档当时的原文、人物、手记和待选行动开始，原路线停在它原有的进度。新路线沿用该手动存档所属的作品设定，即使作者此后改过稿。 |
| 从开场再体验一次 | 在作品页点「重新开局」 | 使用作者当前保存的作品。可以重新填写作者留出的主角信息，主要人物按该作的生成方式确定。旧路线可在「所有路线」找回。 |

手动存档可以保留多个。尚无记录时，列表说明在下一次选择前如何保存。等待新回应或回看历史时，界面标明当前可以保存的是哪个决定点。只在完整决定点开放保存；从存档另开前先预览，避免误把历史阅读位置当作当前进度。

### 中断与恢复

- **尚未发送。** 输入保留为该决定点的草稿，再次进入时由玩家决定是否发送。
- **已经发送。** 等待时可以离开。回来后，若回应已完成就展示这一次的结果；若失败，保留原话，允许重试或改写。续写中断时在已提交的行动下标明「本段未完成」，保留上一段完整正文和状态。成功重试后接上一段完整回应，同一行动只产生一次后果。
- **保存失败。** 明确提示哪一步尚未保存，保留眼前的剧情、输入或手动存档名称供重试。此时离开，告知可恢复到哪里。
- **开场加载失败。** 保留这次开局已经填好的主角信息和已确定的主要人物，提供「重试这次开局」与「返回作品库」。在此重试沿用同一次开局。

## 6. 抵达结局，或暂时告一段落

有结束条件的作品，由 AI 根据本路线的经历判断是否可以收束。最后一段回应已发生的关键选择，并将这条路线标为完结。玩家能回看、从旧手动存档分线或重新开局。结尾这一段同样可以「换一种发展」。采用另一版后，按那一版是否仍满足结束条件，显示结局或恢复下一步行动。开放式作品的阶段目标完成后，剧情可以自然停顿；保留当下可采取的行动和继续游玩的入口。

## 7. 贯穿验收与边界走查

**通用走查。** 任取一部作品，完成开局，分别使用推荐项和自由输入，产生一项对后续有影响的变化。在下一个决定点手动存档，退出再续玩。让原路线继续，然后从存档另开并采取不同行动。核对两条路线共享此前经历、独立保留各自后果；分别从手记跳回本路线的原文。

> **两个题材的验收示例。** 在恋爱作品里，赴约与失约可以带来不同的关系变化。在探索作品里，分享与保留一条线索可以让不同的人知情。两者使用同一套存档、分线与手记流程。

| 再验证的情形 | 通过的表现 |
| --- | --- |
| 同一行动分别处于提议、已发生、后续已改变三个阶段 | 状态栏和手记对应各自阶段，选项保留重要决定给玩家。 |
| 两版回应对同一状态产生不同结果 | 打开候选、取消比较，原版仍可继续。采用候选后，正文、状态和手记只反映所选版本的后果。从替换前已有的手动存档另开，仍能看到旧版状态。 |
| 最新回应触发结局，玩家打开重写又取消 | 原结局仍可回看。若采用另一版，则只按采用结果显示「已完结」或下一次决定点。 |
| 重读前文时新段落到达 | 阅读位置保留；能返回最新行动处；过去的选项不会意外提交。 |
| 不同题材分别配置行动提示和状态 | 各作品使用自己的初始栏目和提示方式；动态栏目不泄露未知信息。 |
| 本机开启了插图 | 选「本局纯文字」，开始故事并提交行动 | 正文和行动照常，开场和续写都没有插图占位。 |
| 一张图放在人物摘下面具之前 | 等图出现，再从旧存档另开并重画原段的图 | 图和说明都保留当时的伪装与称呼。 |
| 一人递出钥匙，另一人把手收回 | 等图到达，再打开大图 | 画面能看出谁在递钥匙、谁收回了手，说明与正文中的动作一致。 |
| 玩家站在闸杆前，还没决定要不要扳下 | 先读到眼前的局面，再选择扳下闸杆 | 决定前的图只画当时的局面。灯亮的画面出现在行动结果对应段落之后。 |
| 出图服务离线时开局并玩到一个配图场面 | 继续阅读，服务上线后重试其中一张图 | 剧情照常推进，只有选中的图开始重试，阅读位置保留。 |
| 提交前、等待中、保存后分别离开 | 回来能认出草稿、已提交行动和已保存结果，重试只产生一次经历。 |
| 作者改稿后继续、分线、全新开局 | 前两者沿用原来的世界与经历，全新开局采用作者后来保存的设定。 |

每回合的上下文、校验和保存见[回合循环](./turn-loop.md)，回合树、路线和存档的存储见[数据模型](./data-model.md)。
